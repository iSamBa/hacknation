# iConcierge

## MVP Scope

### Step 1 : Singe call + Appointment booking

- Agent calls the provider
- Negociates a timeslot
- Checks the availability using the calendar
- Books the slot

### Step 2 : Agentic - Tool Calling

- Access tools mid-conversation
  - Calendar
  - Provider lookup
  - Distance calculation
  - Slot validation / confirmation
- Asks clarifying questions
- Adapts negociation

### Step 3 : Swarm mode

- Simultaneously call up to 15 providers
- 1 voice agent per call
- Scoring
  - Google rating
  - Earliest available
  - Distance/travel time
  - User preferences weighting
- Returns ranked shortlist for confirmation

### Step 4 : Smart preferences

- Prevent double booking -> realtime calendar check
- cross-references proposed slots with user preferences
- User preference enfine combining
  - Google place rating
  - Travel distance
  - Availibility timing
  - Custome user weighting
